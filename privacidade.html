Política de Privacidade

O Assistente da Família é um assistente privado, de uso pessoal, usado apenas pelos membros de uma família. Esta política explica como ele trata os dados das contas Google que o autorizaram.

Dados acessados

  • Gmail: leitura de mensagens (para resumir e avisar sobre e-mails importantes) e criação de rascunhos. O assistente não envia e-mails por conta própria e não apaga mensagens.
  • Google Agenda: leitura e criação de eventos, para lembretes e compromissos.

Uso e compartilhamento

Os dados são usados só para as funções do assistente, para a própria pessoa que autorizou. Não são vendidos, não são usados para publicidade e não são compartilhados com terceiros, exceto o processamento do texto por um provedor de inteligência artificial (Anthropic) para gerar as respostas, sem uso para treinar modelos.

O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Armazenamento

As credenciais de acesso e os dados ficam num servidor privado da família. Trechos de e-mails só ficam guardados pelo tempo necessário para a função pedida.
